# Launcher icons

`battlenet.png` is the 256px application icon extracted from Blizzard's
Battle.net Launcher.exe with icoutils. It is packaged here so new installs
have an icon before Battle.net creates its Wine prefix. The artwork belongs
to Blizzard Entertainment.

Semu uses ES-DE's upstream icon from the pinned Semu input. Moonlight,
chiaki-ng, and Chrome use their packaged upstream icons. SVGs are rendered
to PNG for Steam's shortcut icon loader; KDE and Steam share these assets.
