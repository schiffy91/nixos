# Mac configuration

The checkout is `~/Drive/dev/nixos`. `darwin.nix` supplies this Mac's settings
and Home Manager import. `nix/settings.nix` defines policy; modules under
`nix/system/darwin` and `nix/home` apply it. Linux retains its original host
lookup and app modules, and shares `nix/home` with the Mac.

The package list matches the previously active nix-darwin configuration.
The shell retains the original `.local/bin/env` initialization, `setopt
no_nomatch` and LM Studio path. The `clauded` alias and the `print-files` and
`extract-substring` helpers live in `nix/home/shell.sh`, which Linux shares and
both shells read; Home Manager's zsh module now generates `~/.zshrc` and
`~/.zprofile`. The existing `nix-update` and `nix-upgrade` aliases now target
this repository. No editor is selected.

`settings.apps.git.includes` points to the preserved private Git configuration
at `~/.config/git/local-before-nix.gitconfig`. Keep that file with a machine
backup; it retains identity, signing and credential-helper settings.

The existing agent rules and selected skills from `~/Home` are managed through
Home Manager, from the same `nix/home/agents` tree Linux uses.
Cloud exports and the LM Studio preset are no longer generated by this migration.
The complete original agent sources remain in `~/Home`.

## Apply

From `~/Drive/dev/nixos`:

```sh
nix build .#darwinConfigurations.mbp21.system --no-link
sudo darwin-rebuild switch --flake .#mbp21
```

To apply only user configuration:

```sh
home-manager switch -b before-macos-nix --flake .#alexanderschiffhauer@mbp21
```

Darwin activation requires administrator authentication. Determinate retains
ownership of the Nix daemon. Security defaults preserve the inspected firewall,
guest-login, screen-lock and automatic-update choices, including stealth mode off.
Native applications retain their current installers and updaters.

Separate Darwin package inputs preserve the existing Mac pins. `nix-upgrade`
updates `nixpkgs-darwin`, `home-manager-darwin` and `nix-darwin`. Linux inputs
and the shared BTRC pin are unchanged; project tools remain in `shell.nix`.

## Permissions

`settings.macos.permissions` imports `permissions.nix` as reviewable intent:

```sh
nix eval .#darwinConfigurations.mbp21.config.settings.macos.permissions --json
```

This does not grant or verify macOS consent. Claude Desktop and Codex retain
full access, and Chrome Remote Desktop is retained. Their screen/control grants
were verified in System Settings on October 18, 2026. Standalone Claude Code
Full Disk Access was approved but still needs macOS authentication and verification.

## Recovery

My additions to `~/Home` were removed. Its files match the saved pre-migration
working tree, including the user's uncommitted changes and Steam Deck setup.
Use this repository for Mac activation. The former active system configuration
at `~/.config/nix-darwin` remains available for recovery.

Original shell and Git files were saved with the `.before-macos-nix` suffix.
Home Manager generations can roll back managed configuration; they cannot
restore deleted application data. Establish a backup and test a restore before
removing applications or data. Native-app inventory and private review findings
are kept outside the public configuration.
